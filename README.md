# FastAPI_with_React_FE

A full-stack web application built with **FastAPI** as the backend REST API and **React** as the frontend user interface.

This project demonstrates how to build a modern full-stack application using Python and JavaScript technologies, including API development, frontend integration, authentication, database management, and deployment practices.

---

## 🚀 Project Overview

**FastAPI_with_React_FE** is a full-stack application designed to connect a React frontend with a FastAPI backend through RESTful APIs.

The goal of this project is to learn and implement:

- Backend API development using FastAPI
- Frontend development using React
- Communication between frontend and backend
- REST API architecture
- Database integration
- Authentication and authorization
- Modern web application structure

---

## 🛠️ Tech Stack

### Backend

- Python 3.x
- FastAPI
- Uvicorn
- Pydantic
- SQLAlchemy
- Alembic (Database migrations)
- PostgreSQL / SQLite
- JWT Authentication

### Frontend

- React.js
- JavaScript / TypeScript
- Vite
- HTML5
- CSS3
- Axios
- React Router

### Development Tools

- Git & GitHub
- Visual Studio Code
- Postman
- Virtual Environment (venv)
